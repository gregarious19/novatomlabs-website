NOVATOM LABS — LOGO KIT
=======================

CONCEPT
A constellation: five nodes linked into a small discovery network, one node
lit Nova-blue with a satellite point. No letterform. The wordmark "Nov" (medium)
+ "Atom" (bold) carries the name; the constellation says connection, search and discovery.

COLORS
Ink         #16181F   (primary / wordmark)
Nova Blue   #2F6BF0   (lit node on light)
Electron    #5B8CFF   (lit node on dark)
Paper       #F4F3EF   (off-white background)

FONTS
Wordmark  : Space Grotesk  (Nov = 500, Atom = 700)
"LABS"    : JetBrains Mono 500, letterspaced
Both are free Google Fonts. Install them before editing the text SVGs.

USAGE
- Default to the horizontal lockup. Use the stacked version in tight/square spaces.
- Use the symbol alone only where the brand is already established (app icons, avatars).
- Keep clear space around the logo equal to the diameter of the lit node.
- Minimum width: 90px (horizontal lockup) / 24px (symbol).
- Don't recolor, stretch, rotate, add effects, or place the dark logo on a busy/dark photo.
